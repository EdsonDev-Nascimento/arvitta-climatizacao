# ❄️ ArVitta Climatização

Landing page profissional e responsiva desenvolvida como projeto conceitual para uma empresa de climatização.

O projeto foi criado com foco em uma apresentação clara dos serviços, boa experiência de navegação e geração de contatos através do WhatsApp.

🔗 **Demo online:**  
https://arvitta-climatizacao.lovable.app/

---

## 📋 Sobre o projeto

A ArVitta Climatização é um projeto desenvolvido para demonstrar uma solução digital voltada para empresas locais do setor de climatização.

A proposta foi criar uma página moderna, objetiva e responsiva, capaz de apresentar os principais serviços da empresa e facilitar o contato de potenciais clientes.

O projeto também foi pensado com foco em conversão, utilizando chamadas para ação distribuídas pela página e acesso rápido ao WhatsApp.

---

## ✨ Funcionalidades

- Layout moderno e responsivo
- Apresentação dos principais serviços
- Seção de diferenciais da empresa
- Processo de atendimento
- Área de avaliações/depoimentos
- Seção de perguntas frequentes
- Formulário de orçamento
- Botões de contato pelo WhatsApp
- Navegação adaptada para dispositivos móveis
