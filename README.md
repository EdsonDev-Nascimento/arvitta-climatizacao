# ArVitta Showcase

Quero que você desenvolva uma landing page profissional, moderna, responsiva e com alto foco em conversão para uma empresa fictícia de instalação, manutenção e higienização de ar-condicionado chamada:

ARVITTA CLIMATIZAÇÃO

Este projeto será usado como PORTFÓLIO de desenvolvimento web, portanto quero acabamento profissional e aparência de um site real de uma empresa bem estruturada.

IMPORTANTE:
Este projeto deve ser uma LANDING PAGE, sem painel administrativo, sem login e sem funcionalidades complexas de sistema.

O principal objetivo do site é gerar leads e direcionar potenciais clientes para solicitar orçamento através do WhatsApp.

========================
IDENTIDADE VISUAL
========================

Quero um design moderno, limpo e confiável.

Paleta sugerida:
- azul petróleo / azul escuro como cor principal
- azul claro/ciano como destaque
- branco
- cinza muito claro nos fundos alternativos
- pequenos detalhes escuros para contraste

A identidade deve transmitir:
- profissionalismo
- confiança
- tecnologia
- conforto
- limpeza
- qualidade

Evitar aparência de template genérico.

Quero uma interface sofisticada, com boa hierarquia visual, bastante espaçamento e microinterações suaves.

Usar bordas arredondadas moderadamente, cards elegantes, sombras discretas e ícones modernos.

O site deve ficar excelente tanto no desktop quanto no celular.
